# Навигация и URL

Применённые фильтры доски задаются query-параметрами `epic_id`, `group_id`,
`assignee_id`, повторяющимся `tag_id`, `column_id`, `q`, `archived=true`.
`me` и `none` сохраняют существующую семантику API. Пустые значения опускаются.
URL восстанавливает элементы управления и данные, включая Back/Forward.

Изменение фильтра заменяет текущую запись истории (`replace`), переход на другую
страницу добавляет запись (`push`). Поиск откладывает запрос данных, но не запись
URL. Сброс удаляет только параметры фильтрации. Вкладки профиля используют `tab`.

Ссылки с доски на карточку содержат `return_to` с полным URL доски. Просмотр и
редактирование сохраняют его. Разрешён только локальный путь `/` с query/hash;
при отсутствии или некорректном адресе кнопка возврата открывает `/`.
