# Навигация и URL

Применённые фильтры доски задаются query-параметрами `epic_id`, `group_id`,
`assignee_id`, повторяющимся `tag_id`, `column_id`, `q`, `archived=true`.
`me` и `none` сохраняют существующую семантику API. Пустые значения опускаются.
URL восстанавливает элементы управления и данные, включая Back/Forward.

Изменение фильтра заменяет текущую запись истории (`replace`), переход на другую
страницу добавляет запись (`push`). Поиск откладывает запрос данных, но не запись
URL. Сброс удаляет только параметры фильтрации. Вкладки профиля используют `tab`.

Ссылки с доски на карточку содержат `return_to` с полным URL доски. Просмотр и
редактирование сохраняют его. Разрешены только локальные пути `/` и `/archive` с query/hash;
при отсутствии или некорректном адресе кнопка возврата открывает `/`.

Карандаш на доске открывает `/cards/:id/edit` напрямую с `edit_return=board`.
После успешного сохранения или нажатия «Отмена» редактор возвращает на доску
по `return_to`, сохраняя фильтры. Маркер возврата переживает перезагрузку страницы.
При ошибке сохранения, включая конфликт версий, редактор остаётся открыт,
а введённый текст сохраняется. Редактирование, открытое из просмотра карточки,
по-прежнему возвращает в просмотр карточки.

## Нативные переходы

`src/features/view-transitions.ts` подключает guards после проверки сессии.
Данные выбранной карточки или проекта загружаются до снимка. Callback нативного
API разрешает подтверждение навигации и ждёт только отрисовки Vue; сетевого
ожидания в замороженном представлении нет. В каждом снимке участвуют область
страницы и максимум один видимый заголовок выбранной сущности.

Смена query не запускает эффект. Ошибка снимка, отмена guard или уменьшение
движения не препятствуют навигации. Позиции страницы и горизонтальной доски
сохраняются в памяти по URL; после полной перезагрузки эта память очищается.

## Архив

`/archive` доступен всем участникам через пункт header после «Проекты», в том
числе в мобильном меню. Фильтры `type`, `project_id`, `q` и `history` живут в URL;
применение формы заменяет текущую запись истории. Переход к карточке или проекту
передаёт `return_to`, кнопка «← Архив» возвращает те же фильтры.

Архивный объект показывается без редактора, формы комментария и изменения
вложений. После восстановления обновляются общий Pinia store и архивная выдача.
В режиме истории прошлые события остаются видимыми с актуальным статусом.
Администратор выбирает режим восстановления проекта в диалоге с количеством
карточек; Escape закрывает диалог, Tab остаётся внутри него, фокус возвращается
к вызвавшему элементу, пока тот остаётся в документе.

Вкладка «Архивация» настроек системы содержит общий столбец завершения и два
независимых срока. Изменение формы требует нового предпросмотра. Конфликт версии
не перезаписывает настройки и не стирает введённые значения.
