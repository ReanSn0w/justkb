## Что мы делаем?

Создаём монолитный Go-backend по контракту `CONTRACT.md`: PostgreSQL-модель, REST API, локальные вложения, персональные токены, stateless remote MCP и встраивание собранного frontend. Внешние сервисы, кроме PostgreSQL, в MVP не добавляем.

## План

  - [ ] Разделить точку входа, конфигурацию, HTTP-слой, доменные сервисы и хранилища.
  - [ ] Добавить валидацию обязательной конфигурации при старте.
  - [ ] Настроить structured logging с маскировкой Authorization, cookie и паролей.
  - [ ] Реализовать request ID, recovery, таймауты сервера и graceful shutdown.
  - [ ] Добавить `/health/live` и `/health/ready`.

- [ ] Создать схему PostgreSQL и миграции

  - [ ] Добавить начальный набор колонок без дублирования при повторном запуске.
