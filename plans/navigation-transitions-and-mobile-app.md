## Что мы делаем?

Дорабатываем существующий Vue 3 + Vue Router + Pinia интерфейс JKB: добавляем плавные View Transitions, комплект иконок и запуск с домашнего экрана телефона в standalone-режиме, устраняем потерю фильтров при навигации. Сохраняем Bulma и текущую серверную архитектуру. Работа ограничена этими улучшениями, без общего редизайна, офлайн-режима, service worker и push-уведомлений.

На iPhone отсутствие панелей браузера относится к запуску установленного веб-приложения с домашнего экрана. Настройка выполняется через HTML-метаданные и web app manifest, а не HTTP-заголовки; обычная вкладка Safari продолжает работать как вкладка.

## Для чего мы делаем?

Сейчас `index.html` содержит только название JKB, контейнер приложения и скрипт. Иконки и настройки установки не подключены. В `App.vue` и `AppLayout.vue` используются обычные `RouterView` без анимации переходов.

Сериализация фильтров уже есть в `src/features/filters.ts`, а `BoardView.vue` записывает их через `router.replace` с задержкой 250 мс. Однако чтение query происходит только при монтировании; отдельного наблюдения за изменениями URL нет. Кнопка возврата из `CardView.vue` открывает `/` без фильтров. Нужно завершить существующий механизм, сохранив текущие имена параметров и ссылки из проектов на доску. Вкладки профиля уже используют query-параметр `tab`; это поведение сохраняем.
