# Идеи для JKB

## Разрешить участникам создавать проекты

Участник может создать проект и использовать его для группировки своих карточек на общей доске без обращения к администратору. Администратор по-прежнему отвечает за общие настройки доски.

- [x] Участник может создать проект в интерфейсе и выбрать его при создании или редактировании карточки.
- [x] REST и MCP разрешают создание проекта участникам в рамках действующих требований к аутентификации и правам токена.

[Завершённый план](plans/done/member-project-creation.md).

Открытый вопрос для отдельной доработки — какие действия с проектом после создания должны быть доступны его создателю.
